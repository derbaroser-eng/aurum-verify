Independent verification for autonomous agents.

Two pay-per-call tools for autonomous agents, one gate, one receipt, one price.

Verification. Send a list of claims and the sources you want them checked against. Get back a machine-readable verdict for each claim — and behind every surviving verdict, a quote that was checked character-for-character against the cited source.

Extraction. Send one URL. Get back title, byline, excerpt, word count, and a clean markdown body with nav, footer, and hidden text stripped out. Hidden content — comments, display:none, zero-width characters — is reported as data, never executed. Same $0.05, same rail.

An agent that checks its own output shares its own blind spots, and produces no evidence trail a third party can audit. This service returns the trail: source URL, verbatim quote, retrieval mode, staleness, and a deterministic reason for the verdict.

Call it

POST /v1/verify/claims
Content-Type: application/json

{
  "claims": ["The library was released in 2019."],
  "sources": [{"url": "https://example.org/release-notes"}],
  "require_verbatim_quotes": true
}

→ 402  PAYMENT-REQUIRED: <x402 v1 challenge>
→ 200  PAYMENT-RESPONSE: <x402 v1 settlement>   (with PAYMENT-SIGNATURE credential)

Headers follow the canonical x402 v1 family: PAYMENT-REQUIRED, PAYMENT-SIGNATURE, PAYMENT-RESPONSE. A nonce buys exactly one answer; replay is 402. An idempotency_key replays the same question for free.

Extract content

POST /v1/extract
Content-Type: application/json

{
  "url": "https://example.org/some-article"
}

→ 402  PAYMENT-REQUIRED: <x402 v1 challenge>
→ 200  { "article": { "title": …, "byline": …, "markdown": … }, "receipt": … }

One URL in, clean content out. Nav, footer, and boilerplate are dropped; hidden content is returned as a list you can inspect, never as text to obey. The same price, the same rail, the same receipt as verification. A refused URL (SSRF guard) or a failed fetch returns 400 and does not bill.

Verdicts

supported

A quotable source states the claim.

contradicted

A quotable source states the opposite.

mixed

Sources disagree with each other.

unverifiable

No quotable source found. A valid, first-class answer — never a confident guess.

Limits — what it will not do

  • It will not certify that a claim is true in the world — it reports what the cited sources say and whether they are quotable.
  • It will not assert anything its own code could not corroborate. If quotes cannot be found, the answer is unverifiable.
  • If no model lane answers, it returns 503 and does not bill.
  • Billing honesty: settlement happens before execution, so a paid call whose evidence does not check out returns a billed unverifiable verdict — never a fabrication.
